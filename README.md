# personal-study-timer
this is a vibe coded personal study timer for me and anyone who wants to use it. it is quite simple and looks very minimalistic and does its job. what more do u need

### Features
- Set any duration (hours, minutes, seconds)
- Quick presets: 25/45/50/60/90/120 minutes
- Start / pause / reset
- Fullscreen
- Space = start/pause
- R = reset
- F = fullscreen
- S = set timer
- Click/tap the screen to show controls
- The page uses no external libraries or network requests

The visual style is inspired by the minimalist flip-clock aesthetic
